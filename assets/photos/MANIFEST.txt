AKV PHOTOGRAPHY - PHOTOGRAPH MANIFEST
================================================================

Every photograph the site asks for, by section, using the exact
filename it looks for. To hand over the studio originals:

  1. Save each file into assets/photos/ under the SAME filename
     listed below (the name is the only thing that has to match;
     the picture itself can be any new photograph).
  2. Open js/data.js and set   photos: 'local'
  3. Reload. Every page picks the new files up.

Specification: longest edge 2500px, JPEG quality 85, sRGB colour.
